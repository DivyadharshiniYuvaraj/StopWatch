Mobile Stopwatch App Duplication

A clean, web-based stopwatch application designed to perfectly mimic a native mobile dark-mode UI. 

Features
* Core Controls: Start, Pause, Resume, and Reset functionality.
* Lap Tracking: Records lap times dynamically in a clean, scrollable three-column layout.
* Millisecond Precision: Accurate counting down to the centisecond.
* Responsive UI: Centered mobile-width container that looks great on both desktop and mobile screens.
* Dark Mode Aesthetic: Deep black background with striking red accent colors for a modern feel.

Technologies Used
* HTML5: Semantic structure and layout.
* CSS: Styling, flexbox layout, and dark mode theme.
* JavaScript: Timer logic, DOM manipulation, and state management.

How to Run the Project
1. Clone or download this repository to your local machine.
2. Ensure all three files (`index.html`, `styles.css`, and `script.js`) are in the same folder.
3. Simply open `index.html` in your web browser (Chrome, Firefox, Safari, etc.) to view and use the stopwatch. No server installation is required!
